area: GitHub Copilot

Přizpůsobte si Copilot podle svých preferencí zadáním vlastních pokynů do souboru `copilot-instructions.md` a škálujte svůj pracovní postup ukládáním opakovaně použitelných výzev do své složky `.github/prompts`.
