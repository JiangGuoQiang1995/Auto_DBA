Utilisez le mode agent pour planifier, modifier, générer et itérer en tandem avec Copilot. Ajoutez vos outils MCP favoris pour travailler encore plus rapidement.

Sélectionnez **Agent** dans la fenêtre de conversation instantanée pour commencer.
