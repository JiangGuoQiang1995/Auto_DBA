---
title: Настройка с помощью инструкций и файлов запросов Copilot
area: GitHub Copilot
featureId: CustomInstructions

---

Чтобы настроить Copilot под себя, запишите индивидуальные инструкции в файл `copilot-instructions.md`, а чтобы масштабировать рабочий процесс, сохраните запросы, пригодные для повторного использования в папке `.github/prompts`.
