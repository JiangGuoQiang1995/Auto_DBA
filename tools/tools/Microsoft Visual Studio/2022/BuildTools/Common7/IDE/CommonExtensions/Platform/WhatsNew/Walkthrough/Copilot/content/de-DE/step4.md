---
title: Konfigurieren mit Copilot-Anweisungen und Prompt-Dateien
area: GitHub Copilot
featureId: CustomInstructions

---

Passen Sie Copilot an Ihre Vorlieben an, indem Sie benutzerdefinierte Anweisungen in eine `copilot-instructions.md`-Datei schreiben und Ihren Workflow skalieren, indem Sie wiederverwendbare Prompts im Ordner `.github/prompts` speichern.
