---
title: Personalizzare con le istruzioni di Copilot e i file delle richieste
area: GitHub Copilot
featureId: CustomInstructions

---

Personalizzare Copilot in base alle preferenze scrivendo istruzioni personalizzate in un file `copilot-instructions.md` e ridimensionare il flusso di lavoro salvando le richieste riutilizzabili nella cartella `.github/prompts`.
